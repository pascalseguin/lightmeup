
### Downloads

| System | File | How to install |
|---|---|---|
| Windows 10/11 | `LightMeUp-Setup-…-windows-x64.exe` | Run it. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**. |
| Windows (no install) | `LightMeUp-…-windows-x64-portable.zip` | Unzip anywhere and run `LightMeUp.exe`. |
| Ubuntu / Debian / Mint / Raspberry Pi OS | `lightmeup_…_all.deb` | `sudo apt install ./lightmeup_…_all.deb`, then start **LightMeUp** from the app menu. |
| Any other Linux (x86-64) | `LightMeUp-…-x86_64.AppImage` | `chmod +x` it and double-click. |

LightMeUp opens in your web browser. Keep its small console window open while you work, and close it to stop.
`SHA256SUMS.txt` lists checksums for every file.
